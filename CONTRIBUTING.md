# Contributing to ChatUI

Thanks for considering a contribution!

## Reporting issues

- Search [existing issues](https://github.com/tomaszrymaszewski/ChatUI-local/issues)
  before opening a new one.
- Include steps to reproduce, expected vs. actual behavior, your OS, and the
  app version.

## Submitting a pull request

1. Fork the repo and create a branch off `main`.
2. Make your change, matching the existing code style.
3. Run `npm run build` and fix any errors before opening the PR.
4. Open a pull request describing what changed and why.
5. Be responsive to review feedback — small, focused PRs merge faster.

By submitting a pull request, you agree that your contribution will be
licensed under this project's [MIT License](./LICENSE).
