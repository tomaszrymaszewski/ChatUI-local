# Security Policy

Privacy and trust are core to ChatUI, so we take security reports seriously.

## Reporting a Vulnerability

Please report security vulnerabilities privately using GitHub's
[private vulnerability reporting](https://github.com/tomaszrymaszewski/ChatUI-local/security/advisories/new)
feature (under the repo's **Security** tab → **Report a vulnerability**).

Do not report security vulnerabilities through public GitHub issues.

We aim to acknowledge reports within a few days and will keep you updated as
we investigate and address the issue.

## Supported Versions

The latest release is the only version that receives security updates.
